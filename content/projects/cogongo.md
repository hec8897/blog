## 프로젝트 개요

K-뷰티 산업이 성장하면서 뷰티 인재에 대한 수요가 급증했지만, 뷰티 업계에 특화된 채용 플랫폼은 존재하지 않았습니다. 구직자들은 여러 채용 사이트를 일일이 확인해야 했고, 기업들은 뷰티 업계 경험이 있는 적합한 인재를 찾기 어려웠습니다.

코공고는 **K-뷰티 인재와 기업을 연결하는 맞춤형 채용 플랫폼**입니다. 단순히 채용 공고만 제공하는 것이 아니라, 인사이트 매거진, 뷰티 업계 뉴스, 회사 소개 등 다양한 콘텐츠를 통해 뷰티 업계 구직자들이 정보를 얻고 커리어를 성장시킬 수 있는 공간을 제공합니다.

### 핵심 성과

MAU 만 명 달성, 네이버 검색 상위 노출, 자연 유입 트래픽 30% 증가, "뷰티 채용은 코공고" 브랜딩 성공, DBD 매거진 인스타 팔로워 2만 증가로 유입 확대

### 주요 기술

React Query 상태 관리, Next.js SSG SEO 최적화, React Hook Form 폼 관리, PDF 변환 시스템, Canvas API 활용

### 주요 타겟 사용자

- 뷰티 업계 취업을 준비하는 구직자 (마케터, MD, 디자이너 등)
- 올리브영, 아마존 TOP 랭킹 브랜드 등 뷰티 기업 채용 담당자

## 주요 기능

### 1. 채용 공고 & 회사 둘러보기

뷰티 업계의 채용 공고를 직무, 지역, 경력 등으로 필터링하여 검색할 수 있으며, 올리브영, 아마존 TOP 랭킹 브랜드를 포함한 회사 정보를 제공합니다.

### 구현 내용

- 채용 공고 검색 및 다중 필터링
- 회사별 채용 공고 목록
- 회사 상세 정보 (브랜딩, 복지, 문화)
- 관심 공고/회사 북마크 기능

### 사용 기술

- React Query를 활용한 검색 상태 관리 및 캐싱
- URL 쿼리 파라미터로 필터 상태 공유 및 북마크 지원
- React Query의 캐시 정책으로 불필요한 API 호출 최소화
- Next.js SSG(Static Site Generation)를 적극 활용하여 SEO 최적화 ([📖 관련 블로그 글 보기](/blog/posts/seo-cogongo))

### 기술적 도전 & 해결

- **[SEO 최적화 📖](/blog/posts/seo-cogongo)**: 채용 공고 페이지가 검색 엔진에 노출되지 않는 문제
  - `getStaticPaths`와 `getStaticProps`로 모든 공고 페이지를 정적 생성
  - ISR(Incremental Static Regeneration)로 60초마다 최신 데이터 반영
  - 회사별 페이지에 맞춤 메타태그 및 Open Graph 설정
  - 결과: 네이버 검색에서 "회사명 + 채용" 키워드 검색 시 상위 노출, 캐러셀 형태로 표기
- **복잡한 필터 조합**: 다중 필터(직무, 지역, 경력, 고용형태 등) 조합 시 상태 관리 복잡도 증가
  - URL 쿼리 파라미터와 React Query 쿼리 키를 동기화
  - 필터 변경 시 자동으로 URL 업데이트하여 공유 가능한 링크 생성
  - 결과: 필터 상태 공유 및 북마크 기능 구현, 사용자 편의성 향상

### 성과

- 네이버 검색에서 **아누아 채용**, **비나우 채용** 등 롱테일 키워드 검색 시 상위 노출
- 검색 결과에서 채용공고 리스트가 **캐러셀 형태**로 표기되어 클릭률 대폭 향상

![네이버 검색 결과 캐러셀](/blog/images/cogongo-carousel-example.png)

- 자연 유입(Organic Traffic) 트래픽 **30% 증가**

### 2. 뷰티 업계 맞춤 이력서

뷰티 업계 특성에 맞춘 이력서 작성 및 관리 기능을 제공합니다.

![이력서 작성 폼](/blog/images/projects/cogongo/resume_edit.png)

### 구현 내용

- 단계별 이력서 작성 폼 (기본정보, 경력, 포트폴리오, 자기소개)
- 실시간 미리보기
- 임시 저장 및 불러오기
- 이력서 PDF 다운로드
- 뷰티 업계 맞춤 항목 (브랜드 경험, 뷰티 자격증 등)

### 사용 기술

- React Hook Form으로 복잡한 폼 상태 관리
  - `useForm`으로 폼 전체 상태 관리
  - `watch`로 실시간 미리보기 구현
- 입력값 유효성 검증
  - 필수 필드 체크
  - 이메일, 전화번호 형식 검증
  - 날짜 유효성 검사 (시작일 < 종료일)
- PDF 변환 라이브러리 적용
  - HTML을 PDF로 변환
  - 이력서 템플릿 레이아웃 최적화

### 기술적 도전 & 해결

- **복잡한 폼 관리**: 20개 이상의 입력 필드를 관리해야 하는 복잡한 구조

  - React Hook Form으로 폼 전체를 하나의 상태로 관리
  - `getValues`, `setValue`로 세밀한 상태 제어
  - 각 섹션(기본정보, 경력, 학력 등)별로 컴포넌트 분리하여 복잡도 감소
  - `watch`를 활용하여 실시간 미리보기와 폼 동기화
  - 결과: 폼 렌더링 성능 개선, 코드 유지보수성 향상

- **PDF 변환 라이브러리 적용**: 웹 페이지를 깔끔한 PDF로 변환하는 것이 어려움

  - 여러 라이브러리 비교 (jsPDF, html2canvas, react-pdf 등)
  - html2canvas + jsPDF 조합으로 구현
  - CSS를 PDF 친화적으로 조정 (A4 사이즈, 페이지 분할 고려)
  - 폰트, 이미지 깨짐 방지를 위한 최적화
  - 브라우저별 렌더링 차이 대응
  - 결과: 높은 품질의 PDF 생성, 다운로드 성공률 95% 달성

- **사용자 이탈 방지**: 긴 폼 작성 중 이탈률이 높음
  - 단계별 진행률 표시 (1/4, 2/4, 3/4, 4/4)
  - API를 통한 자동 저장으로 다음 방문 시 작성 내용 복원
  - 다만, 입력 시마다 API 호출이 발생하여 불필요한 요청이 많음 (개선 필요)

### 성과

- 코공고 이력서로 지원하는 비율 약 **60%** 달성
- PDF 다운로드 성공률 **95%**

### 3. 공고에 즉시 지원/회사와 커피챗/인재풀 등록

다양한 방식으로 회사와 연결될 수 있는 옵션을 제공합니다.

### 구현 내용

- **즉시 지원**: 코공고 이력서로 공고에 바로 지원
- **커피챗 신청**: 채용 담당자와 1:1 커피챗 요청
- **인재풀 등록**: 관심 있는 회사의 인재풀에 등록
- 각 옵션별 간편한 지원 프로세스
- 지원 내역 관리 및 추적

### 사용 기술

- React Hook Form으로 지원 폼 상태 관리
  - 간단한 추가 정보 입력 (자기소개, 포트폴리오 링크 등)
  - 유효성 검증
- 이력서 미리보기 기능
  - 지원 전 작성한 이력서 내용 확인
  - 실시간으로 이력서 수정 가능
- 코공고 이력서로 지원 시 PDF 변환 후 API로 전송
  - 지원 시점의 이력서 정보를 PDF로 변환
  - 변환된 PDF를 백엔드 API로 전송
  - 지원 완료 후 지원 내역에 자동 저장

### 기술적 도전 & 해결

- **PDF 변환과 API 전송의 동기화**: 사용자가 지원 버튼을 클릭했을 때 PDF 생성과 API 전송이 순차적으로 이루어져야 함

  - PDF 생성을 비동기로 처리하고 완료 후 API 호출
  - 로딩 상태 관리로 사용자에게 진행 상황 표시
  - 에러 발생 시 적절한 에러 메시지와 재시도 옵션 제공
  - 결과: 지원 성공률 향상, 사용자 혼란 감소

- **다양한 지원 옵션 관리**: 즉시 지원, 커피챗, 인재풀 등 여러 액션의 상태와 UI를 일관되게 관리
  - 공통 컴포넌트 설계로 코드 재사용성 향상
  - 각 액션별 특화된 폼 필드 동적 렌더링
  - 결과: 개발 속도 향상, 일관된 사용자 경험 제공

### 4. 지원한 후보자 바로보기

![지원자 관리 대시보드](/blog/images/projects/cogongo/resume_preview.png)

기업 회원을 위한 채용 관리 기능으로, 지원한 후보자를 빠르게 확인하고 관리할 수 있습니다.

- 지원자 목록 및 필터링
  - 공고별, 지원 상태별, 날짜별 필터링
  - 검색 기능 (이름, 이메일, 직무 등)
- 지원자 프로필 상세 보기
  - 지원자의 기본 정보, 경력, 학력 등 확인
  - 자기소개 및 포트폴리오 링크
- 지원자 PDF 파일 미리보기
  - Canvas를 활용한 PDF 렌더링
  - 브라우저 내에서 바로 확인 가능
- 지원자 제출 파일 ZIP으로 다운로드
  - 여러 지원자의 이력서를 한 번에 다운로드
  - Blob을 활용한 클라이언트 사이드 ZIP 생성
- 지원 상태 관리
  - 검토중, 합격, 불합격 상태 변경

### 사용 기술

- React Query로 지원자 목록 데이터 관리 및 캐싱
- Canvas API를 활용한 PDF 미리보기
  - PDF.js 라이브러리로 PDF를 Canvas에 렌더링
  - 페이지 네비게이션 및 확대/축소 기능
- Blob API를 활용한 ZIP 파일 생성
  - 여러 PDF 파일을 하나의 ZIP으로 묶어 다운로드

### 기술적 도전 & 해결

- **PDF 미리보기 구현**: 브라우저에서 PDF를 직접 렌더링해야 함

  - react-pdf 라이브러리를 활용하여 PDF 렌더링 구현
  - 페이지별로 Canvas에 렌더링하여 부드러운 스크롤 경험 제공
  - 로딩 상태와 에러 처리로 안정성 확보
  - 결과: 새 탭 열기 없이 빠른 확인 가능, 사용자 편의성 향상

- **ZIP 파일 생성 및 다운로드**: 여러 PDF를 한 번에 다운로드하는 기능
  - Blob API로 메모리 상에서 파일 처리
  - 대용량 파일 처리를 위한 비동기 처리 및 진행률 표시
  - 결과: 서버 부하 감소, 빠른 다운로드 속도

### 5. DBD 매거진 퍼블리싱 페이지

![DBD 매거진 페이지](/blog/images/projects/cogongo/dbd_preview.png)

뷰티 업계 인사이트와 커리어 콘텐츠를 제공하는 매거진 페이지입니다. 코공고 홈페이지와 인스타그램에서 동시 운영하여 브랜드 인지도를 높이고 유입을 확대합니다.

### 구현 내용

- 매거진 아티클 페이지
  - 카테고리별 분류 및 태그 관리
  - 관련 아티클 추천 시스템
- SEO 최적화된 매거진 페이지
  - 각 아티클별 고유 메타태그 설정
  - Open Graph 이미지 동적 생성
- 코공고 홈페이지와 인스타그램 동시 운영
  - 동일한 콘텐츠를 두 플랫폼에서 공유
  - UTM 파라미터를 통한 유입 추적
  - 상호 유입 및 팔로워 증가 효과
- 다양한 반응형 대응
  - PC, 태블릿, 모바일 등 모든 디바이스 최적화
  - 브레이크포인트별 맞춤 레이아웃 설계
  - 터치 인터페이스 고려한 UX 개선

### 사용 기술

- Next.js SSG로 매거진 페이지 정적 생성

- Tailwind CSS로 반응형 디자인 구현
- 이미지 최적화 및 CDN 연동

### 기술적 도전 & 해결

- **다양한 디바이스 반응형 대응**: PC부터 모바일까지 모든 디바이스에서 최적화된 사용자 경험 제공

  - Tailwind CSS의 브레이크포인트 시스템 활용
  - 모바일 퍼스트 접근법으로 설계
  - 터치 인터페이스와 마우스 인터페이스 모두 고려한 UX 설계
  - 결과: 모든 디바이스에서 일관된 사용자 경험 제공, 접근성 향상

- **SEO 최적화**: 매거진 콘텐츠의 검색 엔진 노출 최적화
  - 각 아티클별 고유한 메타태그 및 키워드 설정
  - 구조화된 데이터 마크업으로 검색 결과 품질 향상
  - 결과: 매거진 콘텐츠 검색 노출 증가, 브랜드 키워드 상위 노출

### 성과

- **인스타그램 팔로워 2만 증가**: 코공고와 인스타그램 동시 운영으로 팔로워 대폭 증가
- **유입 확대**: 인스타그램을 통한 코공고 사이트 유입 증가
- **브랜드 인지도 향상**: "뷰티 채용은 코공고" 브랜딩 성공에 기여

### 6. 기업 회원 관리 - 회사 & 공고 등록

기업 회원이 직접 회사 정보와 채용 공고를 등록하고 관리할 수 있는 셀프 서비스 기능입니다.

### 구현 내용

- 회사 정보 등록 및 관리
  - 회사 로고 업로드 및 편집
  - 소개 영상 등록 (YouTube, mp4 등)
  - 운영 브랜드 정보 관리 (브랜드별 로고, 설명)
  - 회사 소개글 작성
  - 복지, 문화, 비전 등 커스텀 섹션
- 채용 공고 작성 및 관리
  - 채용하고자 하는 브랜드 선택 (다중 브랜드 보유 기업 대응)
  - 직무, 경력, 고용형태, 지역 등 상세 정보 입력
  - 공고 상태 관리 (진행중, 마감, 임시저장)
  - 공고 미리보기 기능
  - 공고별 지원자 현황 확인
- 실시간 수정 및 반영
  - 즉시 반영되는 회사 페이지 및 공고 수정
  - 수정 이력 관리

### 사용 기술

- React Hook Form으로 복잡한 입력 폼 관리
  - 다단계 폼 (회사 정보 → 브랜드 정보 → 공고 정보)
  - 실시간 유효성 검증
- 이미지 업로드 및 최적화
  - 이미지 크기 제한 및 압축
  - 프리뷰 기능
- 리치 텍스트 에디터
  - 회사 소개 및 공고 상세 설명 작성
  - 마크다운 또는 WYSIWYG 에디터 지원
- React Query로 데이터 동기화
  - 수정 사항 자동 저장
  - Optimistic Update로 빠른 UI 반응

### 기술적 도전 & 해결

- **다단계 폼 상태 관리**: 회사 정보 → 브랜드 정보 → 공고 정보로 이어지는 복잡한 입력 프로세스

  - React Hook Form의 `useForm`과 Context API를 조합하여 단계별 상태 관리
  - 각 단계의 데이터를 독립적으로 관리하되, 최종 제출 시 통합
  - 뒤로 가기 시 작성 내용 유지
  - 결과: 사용자가 중간에 이탈하더라도 작성 내용 보존, 완료율 향상

- **이미지 업로드 최적화**: 고해상도 이미지 업로드 시 서버 부하 및 로딩 속도 문제

  - 백엔드 proxyRequest를 통한 S3 업로드 로직 구현 (사전 서명된 URL 방식)
  - 결과: 이미지 업로드 시간 50% 단축, 서버 스토리지 비용 절감

- **실시간 미리보기**: 사용자가 입력한 내용이 실제 페이지에 어떻게 보일지 확인

  - React Hook Form의 `watch`로 실시간 데이터 동기화
  - 미리보기 컴포넌트와 실제 페이지 컴포넌트 공유로 일관성 유지
  - 결과: 수정 후 확인 과정 간소화, 사용자 만족도 향상

### 성과

- 기업 회원의 **80% 이상**이 셀프 서비스로 공고 등록
- 공고 등록 시간 **평균 10분 이내**로 단축
- 운영팀의 공고 관리 업무 부담 **70% 감소**
