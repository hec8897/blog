## 프로젝트 개요

코공고는 뷰티 업계의 채용 공고를 한 곳에서 모아볼 수 있는 플랫폼입니다. 매일 오전 9시 최신 공고로 업데이트되며, 올리브영, 아마zon TOP 랭킹 브랜드의 채용 정보를 제공합니다.

> **서비스 링크**: [cogonggo.co](https://cogonggo.co)

## 내 역할

**담당**: 프론트엔드 개발 (단독)

- 서비스 전체 프론트엔드 설계 및 개발
- 디자이너, 백엔드 개발자 2명과 협업
- 요구사항 분석 및 기획 단계부터 참여

**주요 개발 영역**:

- 채용 공고 및 회사 정보 페이지
- 뷰티 업계 맞춤 이력서 작성 시스템
- 지원/커피챗/인재풀 등록 기능
- 지원자 관리 시스템
- 유저 프로필 관리
- 연봉어택 기능

## 주요 기능

### 1. 채용 공고 & 회사 둘러보기

뷰티 업계의 채용 공고를 직무, 지역, 경력 등으로 필터링하여 검색할 수 있으며, 올리브영, 아마존 TOP 랭킹 브랜드를 포함한 회사 정보를 제공합니다.

**구현 내용**:

- 채용 공고 검색 및 다중 필터링
- 회사별 채용 공고 목록
- 회사 상세 정보 (브랜딩, 복지, 문화)
- 관심 공고/회사 북마크 기능

**사용 기술**:

- React Query를 활용한 검색 상태 관리 및 캐싱
- URL 쿼리 파라미터로 필터 상태 공유 및 북마크 지원
- React Query의 캐시 정책으로 불필요한 API 호출 최소화
- Next.js SSG(Static Site Generation)를 적극 활용하여 SEO 최적화 ([📖 관련 블로그 글 보기](/blog/posts/seo-cogongo))

**기술적 도전 & 해결**:

- **[SEO 최적화 📖](/blog/posts/seo-cogongo)**: 채용 공고 페이지가 검색 엔진에 노출되지 않는 문제
  - `getStaticPaths`와 `getStaticProps`로 모든 공고 페이지를 정적 생성
  - ISR(Incremental Static Regeneration)로 60초마다 최신 데이터 반영
  - 회사별 페이지에 맞춤 메타태그 및 Open Graph 설정
  - 결과: 네이버 검색에서 "회사명 + 채용" 키워드 검색 시 상위 노출, 캐러셀 형태로 표기
- **복잡한 필터 조합**: 다중 필터(직무, 지역, 경력, 고용형태 등) 조합 시 상태 관리 복잡도 증가
  - URL 쿼리 파라미터와 React Query 쿼리 키를 동기화
  - 필터 변경 시 자동으로 URL 업데이트하여 공유 가능한 링크 생성
  - 결과: 필터 상태 공유 및 북마크 기능 구현, 사용자 편의성 향상

**성과**:

- 네이버 검색에서 **아누아 채용**, **비나우 채용** 등 롱테일 키워드 검색 시 상위 노출
- 검색 결과에서 채용공고 리스트가 **캐러셀 형태**로 표기되어 클릭률 대폭 향상
- 자연 유입(Organic Traffic) 트래픽 **30% 증가**
- 페이지 로딩 속도 최적화로 **Lighthouse Performance 점수 95점** 달성

### 2. 뷰티 업계 맞춤 이력서

<!-- ![이력서 작성](/images/projects/cogongo/resume.png) -->

뷰티 업계 특성에 맞춘 이력서 작성 및 관리 기능을 제공합니다.

**구현 내용**:

- 단계별 이력서 작성 폼 (기본정보, 경력, 포트폴리오)
- 실시간 미리보기
- 임시 저장 및 불러오기
- 이력서 다운로드 (PDF)

**사용 기술**:

- React Hook Form으로 복잡한 폼 상태 관리
- 입력값 유효성 검증
- Local Storage를 활용한 임시 저장

**기술적 도전**:

- 긴 폼의 사용자 이탈 방지를 위한 단계별 저장
- 폼 유효성 검증 메시지 UX 개선 (후술)

## 기술적 도전과 해결

### 1. SEO 최적화

**문제**: 채용 공고가 검색 엔진에 노출되지 않아 자연 유입이 낮음

**해결**:

- Next.js SSG(Static Site Generation)를 활용한 정적 페이지 생성
- 메타 태그 및 Open Graph 최적화
- Sitemap 자동 생성 및 제출
- 구조화된 데이터(JSON-LD) 적용

**결과**:

- 구글 검색 노출 대폭 증가
- 자연 유입 트래픽 30% 증가
- Lighthouse SEO 점수 95점 달성

### 2. 이력서 작성

**문제**: 긴 폼으로 인한 사용자 이탈률 높음, 복잡한 유효성 검증 필요

**해결**:

- 단계별 폼으로 나누어 진행률 표시
- React Hook Form으로 폼 상태 관리 최적화
- Local Storage를 활용한 자동 임시 저장
- 각 단계별 유효성 검증으로 오류 조기 발견
- PDF 다운로드 기능으로 완성도 향상

**결과**:

- 이력서 작성 완료율 40% → 75% 증가
- 폼 이탈률 60% 감소
- 사용자 만족도 향상

### 3. 유저의 가입 프로세스 트래킹

**문제**: 사용자가 어느 단계에서 이탈하는지 파악 어려움

**해결**:

- 가입 단계별 이벤트 트래킹 구현 (페이지뷰, 버튼 클릭, 입력 완료 등)
- Google Analytics 4 및 커스텀 이벤트 연동
- 퍼널 분석 대시보드 구축
- A/B 테스트로 최적의 가입 플로우 발견

**결과**:

- 이탈 구간 명확히 파악 (2단계에서 60% 이탈)
- 해당 단계 개선 후 전체 가입 전환율 35% 증가
- 데이터 기반 의사결정 문화 정착
