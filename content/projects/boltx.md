## 프로젝트 개요

기존 채용 방식은 구직자가 회사에 지원하고 결과를 기다리는 수동적인 구조였습니다. 특히 우수한 IT 인재의 경우, 여러 회사에 지원서를 넣고 기다리는 것이 비효율적이고, 자신의 시장 가치를 제대로 평가받기 어려웠습니다.

볼트엑스는 이러한 채용 방식을 뒤집었습니다. **인증된 구직자에게 회사가 먼저 연봉을 제안하는 역제안 플랫폼**입니다. 건강보험 기반 경력 인증을 통해 구직자의 연봉과 경력을 투명하게 검증하고, 기업들이 우수 인재에게 직접 입찰하듯 연봉을 제안하는 새로운 방식의 이직 플랫폼입니다.

### 주요 타겟 사용자

- IT 업계 이직을 고려하는 개발자 및 IT 종사자
- 우수 IT 인재 채용을 원하는 기업 채용 담당자

### 핵심 성과

- **누적 가입자 30,000+ 달성** (정식 런칭 2년 기준)
  - 2023년 6월 MVP '연봉어택' 시작 → 2024년 1월 정식 런칭
  - IT 역제안 채용 플랫폼으로 성공적인 사용자 확보
- **연간 매출 15억 원 이상 달성** (런칭 2년차 기준)
  - IT 인재 역제안 플랫폼 시장에서 성공적인 수익화 모델 구축
  - B2B(기업/에이전트) + B2C(구독) 복합 수익 구조
- **구직자 매칭률 15% 달성**
  - 업계 평균 대비 높은 매칭률 기록
  - 건강보험 기반 경력 인증으로 신뢰도 높은 구직자 풀 확보
- **3개 프로덕트 동시 운영**
  - 구직자, 어드민, 비즈니스 프론트엔드 단독 개발 및 유지보수

## 담당 업무

### 프론트엔드 개발 (단독)

- 서비스 전체 프론트엔드 설계 및 개발
- **코공고 프로젝트와 동일한 모노레포에서 공통 모듈 공유 및 관리**
- 구직자, 어드민, 비즈니스 3개 프로덕트 전체 프론트엔드 개발
- 퍼블리싱, UI 개발, 프론트 로직 설계, CI/CD, 모니터링
- PO, Marketer, BE, PD와 협업
- 요구사항 분석 및 기획 단계부터 참여

### 주요 개발 영역

- **건강보험, 국세청 기반 경력 인증 시스템**: 카카오 지갑을 활용한 경력 인증
- **구직자 정보 입력 및 관리**: React Hook Form으로 지원 폼 상태 관리
- **기업용 어드민**: 후보저에게 제안, 메시지 보내기 등 구직자 기업간의 연결을 위한 지원
- **에이전트(해드헌팅) 사업 어드민**: 헤드헌팅 사업을 위한 대시보드 지원

## 주요 기능

### 1. 구직자 서비스

구직자가 자신의 경력을 인증하고, 회사로부터 연봉 제안을 받을 수 있는 서비스입니다.

#### 건강보험/국세청 기반 경력 & 연봉 인증

- 카카오톡 인증 또는 PASS 인증 연동
- 건강보험 또는 국세청 인증을 통한 경력 검증
- 인증된 연봉 및 재직 기간 자동 입력

#### 구직자 정보 입력

- 기술 스택, 경력 사항, 희망 연봉 등 상세 정보 입력
- 단계별 폼으로 구성

#### 트래킹 시스템

- UTM 파라미터 기반 유입 경로 추적 및 가입 단계별 이탈 분석 시스템 설계
- 각 단계별 이탈률 분석
- Google Analytics를 활용한 단계별 이벤트 트래킹

#### 사용 기술

- React Hook Form으로 구직자 정보 입력 폼 관리
- 카카오톡 인증/PASS 인증 API 연동
- Google Analytics 를 활용한 가입 플로우 트래킹
- React Query로 인증 상태 및 구직자 데이터 관리
- Sentry를 활용한 에러 트래킹 및 모니터링

#### 기술적 도전 & 해결

- **외부 인증 서비스 연동**: 건강보험공단/국세청 인증 정보를 외부 서비스를 통해 가져옴
  - 각 인증 방식에 맞는 공통 인터페이스 설계
  - 인증 성공/실패 케이스별 에러 핸들링
  - 결과: 두 가지 인증 방식을 통합하여 사용자 선택권 제공
- **가입 플로우 최적화**: 복잡한 정보 입력으로 인한 이탈 방지
  - 단계별 진행률 표시 및 GA 이벤트 트래킹으로 이탈 구간 파악
  - 데이터 분석을 통해 이탈률이 높은 단계 발견
  - 개선 방향을 제안하고 PO/PD와 논의하여 해당 단계 UX 개선
  - A/B 테스트를 통한 효과 검증
  - 결과: 이탈률 감소 및 가입 완료율 향상, 데이터 기반 의사결정 프로세스 정착

### 2. 어드민

어드민은 **마스터**, **에이전트**, **네트워크 유저** 3가지 권한으로 나뉘며, 각 권한별로 접근 가능한 기능이 다릅니다.

#### 구직자 네트워크

- 도입 기업(네트워크 유저)이 인증된 구직자를 탐색하고 연봉 제안을 할 수 있는 대시보드입니다.

#### 구직자 목록

- 마음에 드는 구직자를 저장하고 관리하는 폴더역할을 하는 기능

#### 구직자 프로필 상세 보기

- 구직자의 기본 정보, 경력, 기술 스택 확인
- 연봉 정보는 정기 구독 결제 후 확인 가능

#### 에이전트 대시보드

- 해드헌팅 사업을 위해 고객사와 해드헌터가 구직자 정보를 공유할 수 있도록 만든 대시보드입니다.

#### 연봉 제안 기능

- 구직자의 연봉을 제외한 정보를 보고 제안 가능
- 연봉 확인을 원하는 경우 토스 페이먼츠 정기 구독 결제 필요
- 제안 현황 관리 및 구직자 응답 확인

#### 사용 기술

- React Hook Form으로 복잡한 입력 폼 관리
- react query 를 활용하여 데이터 패칭, 복잡한 필터 구현
- 토스 페이먼츠 정기 결제(빌링) API 연동
- 권한별 접근 제어 로직 구현

#### 기술적 도전 & 해결

- **권한별 접근 제어**: 마스터, 에이전트, 네트워크 유저 각각 다른 기능 제공 필요
  - 권한 기반 라우팅 및 컴포넌트 렌더링 로직 구현
  - Recoil 상태 관리 활용
  - 권한별 UI/기능 분기 처리
  - 결과: 하나의 어드민에서 3가지 권한을 효율적으로 관리
- **토스 페이먼츠 정기 결제 연동**: 연봉 정보 열람을 위한 구독 모델 구현
  - 토스 페이먼츠 빌링키 발급 및 관리
  - 구독 상태에 따른 UI 분기 (미구독/구독 중/구독 만료)
  - 결제 성공/실패 케이스 처리
  - 결과: 안정적인 구독 결제 시스템 구축

#### 에이전트

헤드헌팅 기업과 헤드헌터를 위한 구직자 매칭 및 전형 관리 대시보드입니다.

#### 구직자 수집 및 관리

- 사내외 에이전트 직원들이 구직자 정보 수집
- 구직자 데이터베이스 구축 및 관리

#### 고객사 구직자 제공

- 에이전트 고객사에게 적합한 구직자 추천
- 구직자 프로필 공유 및 매칭

#### 전형 관리 프로세스

- 서류 전형, 면접, 최종 합격까지 단계별 관리
- 진행 상황 트래킹 및 현황 대시보드
- 고객사-구직자 간 커뮤니케이션 지원

#### 사용 기술

- React Query로 복잡한 전형 상태 관리
- 권한별 데이터 접근 제어

#### 기술적 도전 & 해결

- **복잡한 전형 프로세스 관리**: 여러 구직자와 고객사의 다단계 전형을 동시에 관리
  - 각 단계별 액션 및 알림 시스템 구현
  - 결과: 체계적인 전형 관리 및 효율적인 업무 프로세스 구축

### 3. 비즈니스

볼트엑스 도입을 희망하는 기업을 위한 B2B 랜딩 페이지입니다.

- B2B 랜딩 페이지
- 희망 기업 신청폼
- 블로그 작성 및 게시 기능
- SEO 최적화 적용

## 배운 점

### 기술적 측면

- **React Hook Form 심화**: 복잡한 다단계 폼, 동적 필드 관리 등 고급 기능 활용
- **React Query 캐싱 전략**: 서버 상태 관리 및 효율적인 데이터 패칭 패턴 학습
- **카카오 지갑 인증 플로우 & 로그인**: 외부 인증 서비스 연동 및 OAuth 흐름 이해
- **Sentry 에러 트래킹**: 실시간 에러 모니터링 및 사용자 피드백 수집을 통한 안정성 향상
- **Monorepo 관리**: 볼트엑스 3개 프로덕트(구직자, 어드민, 비즈니스)와 코공고를 하나의 monorepo에서 관리하며 코드 공유 및 의존성 관리 경험

### 협업 측면

- 3개 프로덕트를 단독 개발하면서 체계적인 코드 구조의 중요성 인식
- PO/PD와 긴밀한 협업으로 데이터 기반 의사결정 프로세스 정착
- 권한별 접근 제어 등 복잡한 비즈니스 로직 구현 경험

### 개선하고 싶은 점

- 볼트엑스 디자인 시스템 구축으로 컴포넌트 재사용성 향상
- 테스트 코드 작성으로 코드 품질 및 유지보수성 개선
